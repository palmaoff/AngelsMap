# map_core

Общее ядро внешней карты (Leaflet-клиент): `js/map.js`, `js/settings-form.js`, плагины бэкендов в `js/backends/`.
Ядро ничего не знает о смысле слоёв — сервер присылает в `GET /layers` мета-описание, ядро рисует.

## Мета линейного слоя (`type: "line"`)

Все поля опциональны.

- `overlays: [{ field, color, selectedColor }]` — подсветки участков: поверх основной линии рисуются
  некликабельные полилинии по полю объекта `field` (массив точек). `selectedColor` — цвет оверлея
  у выделенного объекта. Порядок в массиве = порядок наложения.
- `geometryField: "zoneDots"` — брать геометрию линии из этого поля объекта вместо `dots`.
  Объект с пустой геометрией не рисуется. Воспроизведение трека играет то, что нарисовано.
- `highlightNoRoute: true` — **legacy-алиас** (traffic monitor): то же, что оверлей
  `{ field: "noRouteDots", color: "red", selectedColor: "#AA226F" }`, если такого оверлея в `overlays` нет.
- `legend: [{ label, color }]` — легенда слоя (у любого типа слоя), видна пока слой включён;
  после сохранения настроек слоя `meta` перечитывается и легенда обновляется.

## Формы настроек

Сервер отдаёт HTML формы; клиент понимает атрибуты строк:

- `data-show-if="поле=значение"` — показывать строку только при таком значении поля.
- `data-exclusive-with="поле1,поле2"` — у чекбокса: при включении снимаются отметки с перечисленных
  чекбоксов (одно имя или список через запятую).
